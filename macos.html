Before you open it

This is a development preview and is not notarized by Apple. Automated tests pass on Apple Silicon and Intel; installation and login behavior still need manual validation. See the Mac guide for details.

The portable app asks you to choose an archive at each launch and does not enable Start at login. New installations save notes in ~/Library/Application Support/Jotilla/notes. Updates keep your existing profile and archive.

Back up the whole archive, including notes.ini and RTF files.
